## 📋 Quick Overview

### What is Freeze of Gait (FoG)?
Freeze of Gait is a sudden, brief inability to generate effective stepping in patients with Parkinson's disease. This VR system helps clinicians:
- **Evaluate** symptom severity in controlled environments
- **Monitor** disease progression over time
- **Support** rehabilitation through immersive therapy
- **Research** behavioral patterns and treatment efficacy

### Project Status
- ✅ **FoG_Revised**: 6 scenarios (Baseline + 5 specialized)
- ✅ **FoG_Walkways**: 3 environmental scenarios
- ✅ **VR Runtime**: Meta Quest 3/Pro compatible
- 📈 **In Active Development**: Regular feature updates

## 🎮 Quick Start (5 minutes)

### Prerequisites
- Meta Quest 3 headset (fully charged)
- Windows PC with 16GB RAM, NVIDIA RTX 2060+
- Unity 2022.3 LTS installed
- Meta XR SDK imported

### Run Your First Scenario
```bash
# 1. Clone/open project
cd C:\Users\user\workspaces\unity\FoG_Revised

# 2. Open in Unity Hub
# Select project → Open with 2022.3 LTS

# 3. In Unity Editor
File → Open Scene → Assets/Scenes/ScenarioMenu.unity

# 4. Connect headset
# Ensure Quest Link is enabled in Meta Horizon App

# 5. Press Play ▶
# Head-track in headset to verify connection
```

**Expected Result**: ScenarioMenu loads in VR, buttons are interactive.

## 🔧 Core Systems

### Player Input (OVRInput)
```csharp
// Handled in PlayerMovement.cs
OVRInput.Button.PrimaryIndexTrigger  // Walk forward
OVRInput.Button.Four                  // Y button → Return to menu
OVRInput.Get(OVRInput.Axis2D.PrimaryThumbstick) // Head orientation
```

### Scene Navigation
```csharp
// ReturnToMenu.cs
SceneManager.LoadScene("ScenarioMenu"); // Return to menu
```

### Metrics Collection
```csharp
// MetricsCollector.cs (runs in Update)
- Track player position every frame
- Calculate distance, speed, acceleration
- Detect environmental triggers
- Save to JSON on completion
```

## ⚙️ System Architecture

```
VR Headset (Meta Quest 3)
        ↓ (Tracking + Input)
  Unity Runtime
        ↓
  OVRCameraRig (player view)
  OVRManager (XR lifecycle)
  InputManager (controller input)
        ↓
  Scenario Logic
  ├─ PlayerMovement
  ├─ MetricsCollector
  ├─ EnvironmentTriggers
  └─ UIManager
        ↓
  Results Output (JSON)
        ↓
  Local Storage / Cloud
```
